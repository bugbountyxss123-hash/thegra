# ثغرة: أكاديمية أمن الذكاء الاصطناعي بالعربي

موقع ثابت (HTML/CSS/JS) بدون قاعدة بيانات ولا تسجيل دخول. ينشر مباشرة على GitHub Pages.

## هيكل الملفات

```
index.html            الصفحة الرئيسية
learn/                الدروس: صفحة لكل درس + index.html (القائمة)
labs/                 المعامل: صفحة لكل معمل + index.html (القائمة)
about/index.html      عن الموقع
assets/style.css      التصميم
assets/data.js        قائمة الدروس والمعامل وأسئلة الاختبارات  ← هنا تسجّل أي إضافة
assets/site.js        القائمة العلوية والتقدّم والاختبارات (لا تحتاج لتعديله عادةً)
assets/labs.js        منطق المعامل التفاعلية
_templates/           قوالب جاهزة لدرس جديد
sitemap.xml           خريطة الموقع لمحركات البحث (غيّر USERNAME و REPO)
```

## إضافة درس جديد (خطوتان)

1. انسخ `_templates/lesson.html` إلى `learn/` وسمّه مثلاً `learn/my-lesson.html`.
   - اكتب المحتوى بدل النص التجريبي.
   - غيّر `<title>` و`description`.
   - في وسم `<body>` غيّر `data-lesson="my-lesson"` ليطابق اسم الملف بدون `.html`.
2. افتح `assets/data.js` وأضف كائناً جديداً في قائمة `lessons`:

```js
{
 "slug": "my-lesson",
 "title": "عنوان الدرس",
 "en": "English Title",
 "level": "مبتدئ",
 "desc": "وصف قصير",
 "quiz": { "q": "السؤال؟", "o": ["خيار ١", "خيار ٢", "خيار ٣"], "a": 1, "e": "شرح الإجابة الصحيحة." }
}
```

ترتيب الدروس في الموقع هو ترتيبها في القائمة. أما السابق والتالي ونسبة التقدّم وصفحة الدروس فتتحدّث وحدها.
أضف السطر الجديد في `sitemap.xml` أيضاً.

## إضافة معمل جديد

1. انسخ أي ملف من `labs/` (غير `prompt-injection.html`) إلى اسم جديد، وغيّر `<title>` وقيمة `data-lab`.
2. أضف المعمل إلى قائمة `labs` في `assets/data.js` (نفس الـ slug).
3. في `assets/labs.js` أضف كائناً بنفس شكل المعامل الموجودة داخل `X`، وشرحه داخل `E`:
   - `ct`: نوع المدخل (`range` أو `select` أو `text`).
   - `f(القيمة, هل_الدفاع_مفعّل)` ترجع `{x: النص, ok: هل نجح الهجوم الآن, s0: هل كان سينجح بدون دفاع}`.

## النشر على GitHub Pages

1. ارفع كل الملفات والمجلدات إلى مستودع GitHub (اسحبها إلى صفحة Upload files).
2. من Settings ثم Pages: اختر Branch اسمه `main` والمجلد `/ (root)` ثم Save.
3. افتح `sitemap.xml` و`robots.txt` وغيّر `USERNAME` و`REPO` إلى اسمك واسم المستودع.

لتجربة الموقع على جهازك افتح `index.html` مباشرة بالمتصفح.
